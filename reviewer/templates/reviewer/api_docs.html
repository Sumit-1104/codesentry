CodeSentry API

← Back to Dashboard

Authentication: All endpoints require an active login session. Log in through the web dashboard first, then access these endpoints from the same browser session.
GET /api/history/

Returns a list of all analyses run by the logged-in user, most recent first.

Example Response

{
  "count": 2,
  "results": [
    {
      "id": 4,
      "source_name": "https://github.com/user/repo",
      "created_at": "2026-09-15T06:33:54.307747+00:00"
    },
    {
      "id": 3,
      "source_name": "sample_code.py",
      "created_at": "2026-09-14T07:24:29.820735+00:00"
    }
  ]
}
GET /api/history/<id>/

Returns the full analysis result for one specific entry, including static analysis, security findings, generated docstrings, and tests.

Example Response

{
  "id": 4,
  "source_name": "sample_code.py",
  "created_at": "2026-09-15T06:33:54.307747+00:00",
  "results": [
    {
      "filename": "sample_code.py",
      "language": "python",
      "static_results": [...],
      "security_results": [...],
      "doc_results": "...",
      "test_results": "..."
    }
  ]
}
GET /history/<id>/pdf/

Downloads the analysis report for a given entry as a PDF file.
